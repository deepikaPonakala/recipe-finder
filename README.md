# Recipe Finder Web Application

The Recipe Finder is a simple and interactive web application built using HTML, CSS, and JavaScript.
It allows users to search for recipes, view images, ingredients, measurements, and full cooking instructions using data fetched from the ThemealDB API.

The project includes a modal recipe viewer, dark/light mode toggle, and a clean responsive UI.

# Features
🔍 Search Recipes

Users can search any recipe by name.

Fetches real-time results from the ThemealDB API.

# Recipe Cards

Displays recipe name, image, category, and area.

Clean grid layout for better browsing.

# Full Recipe Instructions

Clicking on a recipe card opens a modal.

Shows detailed:

Ingredients + measures

Step-by-step instructions

Recipe image

YouTube tutorial link

# Dark Mode / Light Mode

Toggle theme for better accessibility and user comfort.

# Responsive Design

Works smoothly on mobile, tablet, and desktop.

# Technologies Used

HTML5

CSS3 (Flexbox, Grid, Responsive Design)

# How It Works

User types a recipe name into the search bar.

JavaScript fetches results from ThemealDB API:
https://www.themealdb.com/api/json/v1/1/search.php?s=

Search results are displayed in recipe cards.

Clicking a card opens a modal containing full recipe details.

User can switch between dark and light themes anytime.
